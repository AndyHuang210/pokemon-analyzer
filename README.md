# Final Project - Pokémon Data Analysis

This Rust project analyzes Pokémon data from a CSV file. It calculates statistics like total stats per type and counts of legendary Pokémon.

## Dataset

- `pokedex.csv`: Contains Pokémon data including type, height, weight, stats, and evolutionary info.

## Features

- Deserialize CSV data into Rust structs
- Compute stats grouped by Pokémon type
- Identify top Pokémon in each type category
- Count legendary Pokémon
